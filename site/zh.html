如何只读审计 SQLite 迁移前后的变化

比较结构、NULL、存储类型、外键违规与指定重复键，生成离线 HTML / JSON 报告；包含实际命令与可选编程代理 Skill。

精确统计，明确边界

扫描只读，并在一个快照事务中完成。完整扫描较大的数据库可能耗时。行数变化、NULL 增加、混合存储类型仅作为观察结果展示，不会自动触发回归失败。

报告不导出记录正文或重复键的具体值，但会包含建表 SQL 与诊断元数据。分享自己的报告前，请检查这些内容。在线演示仅使用合成数据。
